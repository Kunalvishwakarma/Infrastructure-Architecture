# Architecture Decision Record (ADR) Template

Copy this file for each significant architecture decision.

## Metadata

- **ADR ID:** ADR-000
- **Title:** Short decision title
- **Status:** Proposed / Accepted / Rejected / Superseded
- **Date:** YYYY-MM-DD
- **Decision owner:** Role or team
- **Review date / trigger:** YYYY-MM-DD or defined event

## Context

Describe the problem, drivers, constraints, stakeholders and relevant requirements. Separate confirmed facts from assumptions.

## Decision

State the selected option clearly and explain its scope.
